## 方案一：Google Analytics 4（推荐）⭐

### 优势
- ✅ 完全免费，无限流量
- ✅ 功能强大（实时数据、用户行为分析）
- ✅ 可追踪下载事件
- ✅ 无需后端，纯前端实现

### 实施步骤

#### 步骤1：注册 Google Analytics

1. 访问 https://analytics.google.com/
2. 使用Google账号登录
3. 创建账号和媒体资源
4. 获取"衡量ID"（格式：G-XXXXXXXXXX）

#### 步骤2：添加 GA4 代码到 index.html

在 `<head>` 标签中添加以下代码：

```html
<!-- Google Analytics 4 -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());

  // 配置GA4
  gtag('config', 'G-XXXXXXXXXX', {
    'page_title': '磁盘空间分析工具主页',
    'send_page_view': true
  });
</script>
```

#### 步骤3：追踪下载事件

在下载按钮的点击事件中添加：

```html

   class="download-btn"
   onclick="trackDownload('user_version', 'v1.4.2')"
   download>
    ⭐ 推荐下载：用户版 (15MB)

<!-- 完整版下载按钮 -->

   class="btn btn-outline-primary"
   onclick="trackDownload('full_version', 'v1.4.2')"
   download>
    完整版：含源代码 (16MB)
</a>

<script>
function trackDownload(packageType, version) {
    // 发送下载事件到 GA4
    gtag('event', 'download', {
        'event_category': 'Package Download',
```

1. 访问 https://tongji.baidu.com/
2. 使用百度账号登录
3. 添加网站：`https://gangyincoding.github.io/LargeFileCleaner/`
4. 获取统计代码

#### 步骤2：添加百度统计代码

在 `</body>` 结束标签前添加：

```html
<!-- 百度统计 -->
<script>
var _hmt = _hmt || [];
```

```html
<script>
// 获取 GitHub Release 下载量
async function getDownloadCount() {
    try {
        const response = await fetch('https://api.github.com/repos/gangyincoding/LargeFileCleaner/releases');
        const releases = await response.json();

        let totalDownloads = 0;
        releases.forEach(release => {
            release.assets.forEach(asset => {
                totalDownloads += asset.download_count;
            });
        });

        document.getElementById('download_count').innerText = totalDownloads.toLocaleString();

        console.error('获取下载量失败:', error);
        document.getElementById('download_count').innerText = '统计中...';
    }
}

</script>

    <i class="fas fa-download"></i>
    总下载量：<span id="download_count">Loading...</span>
</div>
```

## 常见问题

### Q1: 为什么不蒜子统计显示为0？
A: 不蒜子需要一定时间初始化，通常1-2小时后会显示数据。

### Q2: GitHub API 有速率限制吗？
A: 未认证请求每小时60次，对于个人网站足够了。

### Q3: Google Analytics 能看到实时下载量吗？
A: 可以，在"实时"→"事件"中可以看到过去30分钟的下载事件。

### Q4: 如何防止统计作弊？
A: GA4 有自动防作弊机制，会过滤机器人流量。百度统计同样有类似功能。
