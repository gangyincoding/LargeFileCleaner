# 🔁 重复文件检测功能使用说明

## 📖 功能简介

重复文件检测功能是磁盘空间分析工具 v1.4 的新增功能，专门用于扫描和识别磁盘中的重复文件。该功能使用MD5哈希算法精确识别内容完全相同的文件，并提供智能保留建议，帮助用户快速释放被重复文件占用的磁盘空间。

## ✨ 功能特点

### 1. 精确重复检测
- **MD5哈希算法**：计算文件的MD5哈希值，确保100%内容匹配
- **分块读取**：8KB分块读取，支持大文件处理
- **内存优化**：避免大文件占用过多内存

### 2. 性能优化
- **两阶段检测**：
  - 第一阶段：按文件大小分组（快速预筛选）
  - 第二阶段：只对大小相同的文件计算哈希值
- **最小文件大小过滤**：可设置最小文件大小，跳过小文件
- **实时进度显示**：扫描过程显示当前处理的文件

### 3. 智能保留建议
自动为每组重复文件推荐保留哪个文件，策略按优先级排序：
1. **修改时间最新**：保留最后修改的版本
2. **路径最短**：保留路径层级较浅的文件
3. **文件名最短**：保留文件名简短的文件

### 4. 清晰的可视化展示
- **树形结构**：重复组作为父节点，文件作为子节点
- **颜色区分**：
  - 浅绿色背景：建议保留的文件
  - 浅黄色背景：可删除的重复文件
- **详细信息**：文件名、大小、完整路径、修改时间

### 5. 批量操作支持
- **单选**：点击复选框选择单个文件
- **多选**：逐个选择多个文件
- **全选重复**：一键选择所有非保留文件
- **智能保护**：建议保留的文件无法选择

### 6. 空间统计
- **实时统计**：显示可释放的磁盘空间
- **分组统计**：每组显示浪费的空间
- **总体统计**：扫描完成后显示总体数据

## 🚀 使用方法

### 步骤1：选择扫描路径
1. 在主界面顶部的"扫描路径"输入框输入路径
2. 或点击"浏览..."按钮选择文件夹
3. 或使用快速选择按钮（下载、桌面、文档等）

### 步骤2：打开重复文件检测页面
1. 点击顶部的"重复文件检测"标签页
2. 确认扫描路径正确

### 步骤3：设置扫描参数
1. **最小文件大小**：设置要检测的最小文件大小
   - 0KB：检测所有文件（不推荐，包含大量小文件）
   - 100KB：跳过小于100KB的文件
   - 1MB：只检测1MB以上的文件（推荐）
   - 10MB：只检测大文件
   - 100MB：只检测超大文件

**建议**：
- 下载文件夹、照片库：1MB或10MB
- 文档文件夹：100KB
- 视频文件夹：10MB或100MB

### 步骤4：扫描重复文件
1. 点击"扫描重复文件"按钮
2. 在弹出的确认对话框中查看设置并点击"是"
3. 等待扫描完成（显示当前处理的文件）
4. 查看扫描结果统计信息

### 步骤5：查看扫描结果

扫描完成后会显示：

#### 统计信息
```
扫描文件总数: 1,234
重复文件组数: 15
重复文件数量: 45
浪费空间: 2.5 GB
```

#### 重复文件组
```
组 1 (3个文件, 浪费 2.5 MB)
  ☑ 文件A.jpg    2.5 MB    D:\Photos\2024\    2024-11-28 10:30:00    ✓ 保留  ← 浅绿色
  ☑ 文件A(1).jpg  2.5 MB    D:\Download\      2024-11-20 15:00:00            ← 浅黄色
  ☑ 副本.jpg      2.5 MB    D:\Backup\        2024-11-15 09:00:00            ← 浅黄色
```

**显示说明**：
- **组号**：重复文件组编号
- **文件数量**：该组包含的文件数量
- **浪费空间**：该组重复占用的空间（文件大小 × (数量-1)）
- **✓ 保留**：智能推荐保留的文件（最新修改时间）
- **颜色**：绿色=建议保留，黄色=可删除重复

### 步骤6：选择要删除的文件

三种选择方式：

#### 方式1：单选
- 点击左侧复选框 ☐ → ☑
- 可以自由选择任意非保留文件

#### 方式2：全选重复
- 点击"全选重复"按钮
- 自动选择所有标记为可删除的重复文件
- 不会选择标记为"✓ 保留"的文件

#### 方式3：手动多选
- 展开不同的重复组
- 逐个选择要删除的文件

**保护机制**：
- 标记为"✓ 保留"的文件无法选择
- 点击时会显示警告提示
- 确保每组至少保留一个文件

### 步骤7：查看删除预览
选择文件后，状态栏会实时显示：
```
已选择 30 个重复文件，可释放 1.8 GB
```

### 步骤8：删除选中的重复文件
1. 点击"删除选中文件"按钮
2. 确认删除警告对话框：
   ```
   确定要删除 30 个重复文件吗？

   文件将被移动到回收站（如果可用）

   此操作无法通过本工具撤销！
   ```
3. 点击"是"确认
4. 等待删除完成（显示进度窗口）
5. 查看删除结果报告

### 步骤9：查看删除日志
所有删除操作都会记录到 `delete_log.txt` 文件中，包括：
- 操作时间
- 删除成功的文件列表
- 删除失败的文件及错误原因

## 📊 重复文件定义

### 什么是重复文件？
重复文件必须同时满足两个条件：

1. **文件大小完全相同**（字节级别）
2. **MD5哈希值完全相同**（内容100%一致）

### 不是重复文件的情况

#### 情况1：文件名相同但内容不同
```
文件A.txt (100 bytes, MD5: abc123)
文件A.txt (100 bytes, MD5: def456)  ← 不是重复（哈希值不同）
```

#### 情况2：内容相似但不完全相同
```
照片_原始.jpg (1 MB, MD5: aaa111)
照片_编辑.jpg (1.05 MB, MD5: bbb222)  ← 不是重复（大小和哈希值都不同）
```

#### 情况3：大小相同但内容不同
```
文件1.dat (1024 bytes, MD5: xxx111)
文件2.dat (1024 bytes, MD5: yyy222)  ← 不是重复（哈希值不同）
```

### 是重复文件的情况

#### 情况1：完全相同的副本
```
原始文件.txt (500 bytes, MD5: zzz999)
副本.txt (500 bytes, MD5: zzz999)  ← 重复（大小和哈希值都相同）
```

#### 情况2：不同名称但内容相同
```
report_2024.pdf (2 MB, MD5: ppp777)
final_report.pdf (2 MB, MD5: ppp777)  ← 重复（内容完全相同）
```

## ⚙️ 性能优化原理

### 两阶段检测算法

#### 阶段1：大小分组（快速）
```
扫描所有文件 → 按文件大小分组 → 过滤只有1个文件的组
耗时：快（只需读取文件属性）
```

#### 阶段2：哈希计算（慢但精确）
```
只对大小相同的文件 → 计算MD5哈希 → 按哈希值分组
耗时：慢（需要读取文件内容）但只处理潜在重复文件
```

### 为什么这样设计？

**示例场景**：扫描包含10,000个文件的文件夹

- **方法1（低效）**：直接计算所有文件的哈希值
  - 需要计算：10,000次哈希
  - 耗时：假设每个文件10ms，总计100秒

- **方法2（高效，本工具采用）**：先按大小分组
  - 大小分组：10,000个文件，几乎瞬间完成
  - 假设只有500个文件大小重复
  - 只需计算：500次哈希
  - 耗时：5秒
  - **性能提升：20倍**

### 内存优化

**分块读取**：
```python
# 每次读取8KB，而不是一次读取整个文件
chunk_size = 8192  # 8KB
while True:
    chunk = file.read(chunk_size)
    if not chunk:
        break
    hasher.update(chunk)
```

**好处**：
- 无论文件多大，内存占用固定（仅8KB）
- 支持处理GB级别的大文件
- 避免内存溢出

## ⚠️ 注意事项

### 1. 扫描时间说明
- 小文件夹（<1000个文件）：通常几秒内完成
- 中等文件夹（1000-10000个文件）：可能需要几分钟
- 大文件夹（>10000个文件）：可能需要较长时间

**建议**：
- 首次使用时先扫描小文件夹测试
- 大文件夹可以在休息时进行扫描
- 设置较大的最小文件大小可加快扫描

### 2. 智能保留建议仅供参考
- 程序只能根据时间、路径判断
- 无法理解文件的实际重要性
- **建议用户仔细检查每组重复文件**

### 3. 特殊情况

#### 隐藏文件和系统文件
- 扫描会包含隐藏文件
- 但受权限保护的系统文件可能无法访问

#### 文件被占用
- 正在使用的文件可能无法计算哈希值
- 删除时被占用的文件会失败

#### 权限问题
- 某些目录可能需要管理员权限
- 权限不足的文件会被跳过

### 4. 删除前的检查清单
- [ ] 确认扫描路径正确
- [ ] 查看每组重复文件的详细信息
- [ ] 验证智能保留建议是否合理
- [ ] 对重要数据先备份
- [ ] 确保回收站功能可用

### 5. 回收站支持
**推荐安装**：

pip install send2trash

**如果未安装**：

## 🔍 常见问题

### Q1：为什么某两个文件看起来一样，但没有被检测为重复？
**A**：可能的原因：
1. 文件大小不同（即使差1个字节也不算重复）
2. 文件内容有细微差别（如编辑过）
3. 文件格式不同（如.txt和.docx虽然内容相同，但格式不同）
4. 元数据不同（如照片的EXIF信息不同）

### Q2：MD5哈希算法安全吗？
**A**：对于重复文件检测来说，MD5完全足够：
- MD5碰撞（两个不同文件产生相同MD5）的概率极低
- 对于普通文件，MD5碰撞几乎不可能发生
- 本工具还会先检查文件大小，增加了额外保护

### Q3：可以中途停止扫描吗？
**A**：目前版本暂不支持中途停止。建议：
- 先在小文件夹测试
- 确认功能符合需求后再扫描大文件夹

### Q4：删除的文件可以恢复吗？
**A**：
- 使用回收站（推荐）：可以从回收站恢复
- 永久删除：无法恢复

### Q5：为什么扫描很慢？
**A**：扫描速度取决于：
- 文件数量
- 文件大小（大文件哈希计算需要更多时间）
- 磁盘读取速度
- 潜在重复文件数量

**优化建议**：
- 增大最小文件大小（跳过小文件）
- 先扫描特定文件类型的文件夹
- 使用SSD固态硬盘

### Q6：智能保留建议为什么选择这个文件？
**A**：保留策略：
1. 修改时间最新（优先级最高）
2. 路径层级最浅
3. 文件名最短

示例：
```
文件A: D:\Photos\2024\IMG_001.jpg (修改: 2024-11-28)  ← 被建议保留
文件B: D:\Backup\Old\Archive\IMG_001.jpg (修改: 2024-10-01)
文件C: D:\Download\IMG_001.jpg (修改: 2024-11-20)

原因：文件A修改时间最新
```

### Q7：可以只删除某一组的重复文件吗？
**A**：可以。使用单选方式：
1. 展开要处理的组
2. 只选择该组中的重复文件
3. 不选择其他组的文件
4. 点击删除

### Q8：误删了文件怎么办？
**A**：
1. **使用回收站的情况**：
   - 打开回收站
   - 找到被删除的文件
   - 右键"还原"

2. **永久删除的情况**：
   - 查看delete_log.txt日志
   - 如有备份，从备份恢复
   - 否则无法恢复
