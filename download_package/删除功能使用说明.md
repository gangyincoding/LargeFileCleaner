# 📝 文件删除功能使用说明

## 🎉 新功能概述

磁盘空间分析工具现已支持**安全文件删除**功能！可以在扫描结果中直接选择文件进行删除，同时具有完善的系统文件保护机制。

## ✨ 主要特性

### 1. 文件选择功能
- ☑️ **单个选择**：点击文件列表中的复选框选择单个文件
- 📋 **批量操作**：支持全选/取消全选功能
- 🔍 **状态显示**：实时显示已选择文件数量

### 2. 安全状态标识
每个文件都会显示安全状态标识：
- ✅ **可删除**：普通文件，可以安全删除
- ⚠️ **需警告**：重要用户数据（如桌面、文档等）
- 🔴 **系统文件**：系统关键文件，禁止删除

### 3. 系统文件保护
自动检测并保护以下系统关键区域：
- `C:\Windows` - Windows系统目录
- `C:\Program Files` - 程序安装目录
- `C:\Program Files (x86)` - 32位程序目录
- `C:\ProgramData` - 应用程序数据
- `C:\Users\<用户名>\AppData` - 用户应用数据
- C盘根目录下的系统文件

### 4. 安全删除机制
- 🗑️ **回收站支持**：优先移动到回收站（需要安装 `send2trash` 库）
- ⚠️ **多重确认**：删除前显示详细警告信息
- 📊 **智能分类**：按安全等级分类显示文件
- 🚫 **自动拦截**：自动拒绝删除系统文件

### 5. 删除日志
- 📝 所有删除操作都会记录到 `delete_log.txt`
- ⏰ 包含时间戳、文件路径、操作结果
- 🔍 便于追踪和恢复

## 🚀 使用方法

### 步骤1：扫描文件
1. 启动程序：双击 `DiskCleaner_GUI_Stable.bat`
2. 选择要扫描的目录
3. 点击"开始扫描"按钮
4. 等待扫描完成

### 步骤2：选择文件
在"最大文件"标签页中：
1. 查看文件列表和安全状态
2. 点击复选框选择要删除的文件
3. 或使用"全选"按钮批量选择
4. 查看底部的选择状态

### 步骤3：删除文件
1. 点击"删除选中文件 (慎重!)"按钮
2. 查看警告对话框中的文件分类
3. 确认无误后点击"是"
4. 等待删除完成
5. 查看删除结果报告

### 步骤4：验证结果
- 已删除的文件会从列表中移除
- 查看 `delete_log.txt` 了解详细信息
- 如需恢复，从回收站还原文件

## ⚙️ 依赖安装

### 可选依赖：send2trash（推荐）
用于安全删除文件到回收站：

```bash
pip install send2trash
```

**注意**：
- ✅ 如果已安装：文件将移动到回收站，可以恢复
- ⚠️ 如果未安装：文件将被永久删除，无法恢复

## 🛡️ 安全保护措施

### 1. 系统文件拦截
- 自动检测C盘系统关键目录
- 禁止删除系统扩展名文件（.sys, .dll等）
- 拒绝删除具有系统属性的文件

### 2. 多重确认机制
1. **选择确认**：通过复选框明确选择
2. **分类警告**：显示文件安全等级统计
3. **最终确认**：删除前再次确认

### 3. 详细日志记录
- 记录所有删除操作
- 包含成功和失败的文件
- 带时间戳便于追踪

## 📋 文件安全等级说明

### ✅ 安全级别 - 可删除
**特征**：
- 位于非系统盘（D盘、E盘等）
- 或位于用户下载、临时文件夹
- 不具有系统文件属性

**示例**：
- `D:\Downloads\movie.mp4`
- `E:\Backup\data.zip`
- `C:\Users\用户名\Downloads\软件.exe`

### ⚠️ 警告级别 - 需警告
**特征**：
- 位于用户重要目录
- 桌面、文档、图片等

**示例**：
- `C:\Users\用户名\Desktop\文档.pdf`
- `C:\Users\用户名\Documents\工作文件.xlsx`
- `C:\Users\用户名\Pictures\照片.jpg`

**建议**：删除前确认文件不重要

### 🔴 危险级别 - 系统文件
**特征**：
- 位于系统关键目录
- 系统扩展名文件
- 具有系统属性标记

**示例**：
- `C:\Windows\System32\*.dll`
- `C:\Program Files\应用\*.exe`
- `C:\ProgramData\*`

**保护**：自动拒绝删除，无法绕过

## 💡 使用建议

### ✅ 推荐删除
1. 下载文件夹中的旧安装包
2. 临时文件夹中的缓存文件
3. 非系统盘的备份文件
4. 已确认不需要的大文件

### ⚠️ 谨慎删除
1. 桌面和文档中的文件
2. 程序配置文件
3. 不确定用途的文件

### 🚫 禁止删除
1. Windows系统目录文件
2. Program Files中的文件
3. 不认识的系统文件

## 🔧 故障排除

### 问题1：删除按钮是灰色的
**原因**：未选择任何文件
**解决**：点击复选框选择至少一个文件

### 问题2：提示"禁止删除系统文件"
**原因**：选择了系统关键文件
**解决**：取消选择红色标记的文件

### 问题3：删除失败
**可能原因**：
- 文件正在被使用
- 没有权限
- 文件已被删除

**解决方法**：
1. 关闭正在使用文件的程序
2. 以管理员身份运行程序
3. 查看 `delete_log.txt` 了解详细错误

### 问题4：无法恢复删除的文件
**情况1**：已安装 send2trash
- 从回收站还原文件

**情况2**：未安装 send2trash
- 文件已永久删除
- 使用专业恢复软件尝试恢复

## 📞 注意事项

1. **删除前备份**：重要文件请先备份
2. **仔细确认**：删除操作不可轻易恢复
3. **查看日志**：遇到问题请查看 delete_log.txt
4. **安装依赖**：建议安装 send2trash 库
5. **系统保护**：程序会自动保护系统文件
