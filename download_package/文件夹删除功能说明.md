# 📁 文件夹删除功能使用说明

## 🎉 新功能介绍

磁盘空间分析工具v1.2版本新增**按文件夹查看和删除**功能！现在您可以直接删除整个文件夹及其所有内容，特别适合多个大文件都在同一文件夹的场景。

## ✨ 核心特性

### 1. 按文件夹分组查看
- 📊 **智能分组**：自动将扫描的大文件按父文件夹分组
- 📈 **统计信息**：显示每个文件夹的文件数量和总大小
- 🔍 **一目了然**：快速识别占用空间最多的文件夹

### 2. 安全状态标识
每个文件夹都会显示安全状态：
- ✅ **可删除**：文件夹及所有内容都可安全删除
- ⚠️ **需警告**：包含重要用户数据（如文档、桌面文件等）
- 🔴 **包含系统文件**：文件夹中有系统关键文件，禁止删除

### 3. 递归安全检查
- 🔒 **深度扫描**：递归检查文件夹中的所有子文件和子文件夹
- 🛡️ **系统保护**：自动拒绝删除包含系统文件的文件夹
- ⚠️ **智能警告**：识别包含用户重要数据的文件夹

### 4. 完整删除
- 🗂️ **一键清理**：删除文件夹及其所有子文件、子文件夹
- 🗑️ **回收站支持**：优先移动到回收站（可恢复）
- 📝 **日志记录**：详细记录所有删除操作

## 🚀 使用方法

### 步骤1：扫描文件
1. 启动程序：双击 `DiskCleaner_GUI_Stable.bat`
2. 选择要扫描的目录
3. 点击"开始扫描"按钮
4. 等待扫描完成

### 步骤2：切换到文件夹视图
1. 在结果区域，点击**"按文件夹查看"**标签页
2. 查看文件夹列表，按总大小排序
3. 查看每个文件夹的：
   - 文件夹路径
   - 包含的文件数量
   - 总大小
   - 安全状态

### 步骤3：选择要删除的文件夹
方式一：单选
- 点击文件夹行首的复选框

方式二：全选
- 点击"全选"按钮选择所有文件夹
- 点击"取消全选"清除所有选择

方式三：双击打开
- 双击文件夹行可以在文件资源管理器中打开该文件夹

### 步骤4：删除文件夹
1. 点击"删除选中文件夹 (慎重!)"按钮
2. 查看警告对话框：
   - 将显示文件夹数量统计
   - 按安全等级分类（安全/警告）
   - 系统文件夹自动拒绝
3. 确认后点击"是"
4. 等待删除完成（显示进度）
5. 查看删除结果报告

### 步骤5：查看日志
- 所有删除操作记录在 `delete_log.txt`
- 包含时间戳、文件夹路径、操作结果

## 🛡️ 系统保护机制

### 自动保护的系统区域
文件夹删除功能会递归检查并保护：
- `C:\Windows` - Windows系统目录
- `C:\Program Files` - 程序安装目录
- `C:\Program Files (x86)` - 32位程序目录
- `C:\ProgramData` - 应用程序数据
- `C:\Users\<用户名>\AppData` - 用户应用数据
- 包含系统文件扩展名（.dll, .sys等）的文件

### 多层保护机制
1. **显示阶段**：红色标记包含系统文件的文件夹
2. **选择阶段**：允许选择但会警告
3. **确认阶段**：递归检查所有子文件和子文件夹
4. **执行阶段**：检测到系统文件自动拒绝整个操作

### 保护示例
```
❌ 禁止删除：
   C:\Windows\System32        → 系统目录
   C:\Program Files\App       → 程序目录

⚠️ 需要警告：
   C:\Users\用户名\Desktop    → 桌面文件夹
   C:\Users\用户名\Documents  → 文档文件夹

✅ 可安全删除：
   D:\Downloads\OldFiles      → 非系统盘文件夹
   E:\Backup\TempData         → 备份数据
```

## 💡 使用场景

### 场景1：清理下载文件夹
**问题**：下载文件夹中有多个大的安装包和压缩包

**解决方案**：
1. 扫描 `C:\Users\用户名\Downloads`
2. 切换到"按文件夹查看"
3. 如果多个大文件都在同一子文件夹，直接选择该文件夹
4. 一键删除整个文件夹

**示例**：
```
Downloads/
├── OldInstallers/       ← 包含多个安装包，总计2GB
│   ├── software1.exe
│   ├── software2.exe
│   └── software3.exe
└── Archives/            ← 包含多个压缩包，总计1.5GB
    ├── project1.zip
    └── project2.zip
```
只需选择 `OldInstallers` 和 `Archives` 两个文件夹即可清理3.5GB空间。

### 场景2：清理项目临时文件
**问题**：开发项目中的node_modules、build文件夹占用大量空间

**解决方案**：
1. 扫描项目目录
2. 在"按文件夹查看"中找到这些临时文件夹
3. 批量选择并删除

### 场景3：清理备份文件夹
**问题**：多个旧备份文件夹占用磁盘空间

**解决方案**：
1. 扫描备份目录
2. 识别不需要的备份文件夹
3. 一次性删除多个备份文件夹

## ⚙️ 技术细节

### 文件夹分组算法
1. 扫描完成后，获取所有大文件列表
2. 提取每个文件的父文件夹路径
3. 按文件夹分组，统计文件数量和总大小
4. 按总大小降序排序

### 安全检查流程
```
选择文件夹
    ↓
递归扫描文件夹内所有文件
    ↓
检查每个文件的安全等级
    ↓
┌─────────────┬──────────────┬─────────────┐
│ 有危险文件？ │ 有警告文件？  │ 全部安全？   │
└─────────────┴──────────────┴─────────────┘
      ↓               ↓               ↓
  🔴 拒绝删除    ⚠️ 警告确认    ✅ 允许删除
```

### 删除操作
1. **send2trash可用**：
   - 使用 `send2trash.send2trash(folder_path)`
   - 文件夹移动到回收站
   - 可以从回收站恢复

2. **send2trash不可用**：
   - 使用 `shutil.rmtree(folder_path)`
   - 永久删除文件夹
   - 无法恢复

## 🔧 故障排除

### 问题1：文件夹列表为空
**原因**：没有足够大的文件或扫描文件数量太少
**解决**：
- 降低最小文件大小设置
- 增加最大文件数量

### 问题2：删除按钮是灰色的
**原因**：未选择任何文件夹
**解决**：点击复选框选择至少一个文件夹

### 问题3：提示"禁止删除系统文件夹"
**原因**：选择的文件夹包含系统关键文件
**解决**：
1. 查看哪些文件夹被标记为🔴
2. 取消选择这些文件夹
3. 只删除安全的文件夹

### 问题4：删除失败
**可能原因**：
- 文件夹正在被使用
- 没有足够权限
- 文件夹中有只读文件

**解决方法**：
1. 关闭正在使用文件夹的程序
2. 以管理员身份运行程序
3. 检查文件夹权限
4. 查看 `delete_log.txt` 了解详细错误

### 问题5：无法恢复已删除的文件夹
**情况1**：已安装 send2trash
- 从回收站还原文件夹

**情况2**：未安装 send2trash
- 文件夹已永久删除
- 尝试使用专业恢复软件

## 📋 与单文件删除的区别

| 特性 | 单文件删除 | 文件夹删除 |
|------|----------|-----------|
| 删除对象 | 单个文件 | 整个文件夹及所有内容 |
| 安全检查 | 检查单个文件 | 递归检查所有子文件 |
| 适用场景 | 精确删除个别大文件 | 批量清理文件夹 |
| 删除粒度 | 细粒度 | 粗粒度 |
| 效率 | 适合少量文件 | 适合批量清理 |

## 🎯 最佳实践

### ✅ 推荐删除的文件夹
- 下载文件夹中的旧安装包文件夹
- 项目的临时构建文件夹（build、dist、node_modules）
- 过期的备份文件夹
- 非系统盘的缓存文件夹

- 桌面上的文件夹
- 文档文件夹中的内容
- 不确定用途的文件夹
- 包含重要数据的文件夹

### 🚫 禁止删除的文件夹
- Windows系统目录
- Program Files目录
- 用户AppData目录
- 任何红色标记的文件夹
